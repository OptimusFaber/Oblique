# Oblique

Desktop VPN-клиент для Windows 10/11 x64 и Linux x64. Интерфейс основан на SilentGuard v2, VPN-ядро — на той же закреплённой ревизии форка sing-box, что и текущий SilentGuard. Лицензия GPL-3.0; исходные авторские уведомления сохранены.

## Использование

1. Установите пакет для своей системы. Ядро включено в установщик.
2. На вкладке «Подключение» раскройте «Импорт профилей и подписок». Вставьте ссылки, откройте TXT-файл или загрузите HTTPS-подписку. Несколько профилей автоматически объединяются в группу с резервным переключением.
3. Выберите сервер и режим: «Прокси» для приложений, использующих системный прокси, либо «Туннель» для системного VPN.
4. Нажмите на логотип. Статус «Подключено» появится после проверки конфигурации, готовности ядра и HTTPS-проверки напрямую через выбранный VPN-сервер.
5. На вкладке «Активность» отображаются настоящие счётчики и соединения. «Избранные сайты» проверяются через SOCKS ядра, без браузерных CORS-эвристик.

Режим прокси не перехватывает приложения, которые игнорируют настройки рабочего стола; для них используйте TUN. Список процессов зависит от возможностей ОС. Наличие HTTP-ответа само по себе не доказывает отсутствие географических ограничений.

### Windows

Приложение запрашивает права администратора для TUN. Установщик ставится для всех пользователей. Настройки прокси меняются для пользователя, запустившего приложение; после остановки возвращается предыдущий ProxyEnable/ProxyServer/ProxyOverride/AutoConfigURL. Wintun встроен в используемую библиотеку ядра. Для интерфейса необходим WebView2; установщик Tauri устанавливает runtime при его отсутствии.

Закрытие приложения отключает VPN. При аварии отдельный watchdog останавливает ядро и восстанавливает прокси; оставшийся после сбоя снимок дополнительно восстанавливается при следующем запуске. Это восстановление прокси, а не системный kill switch.

### Linux

Рекомендуется DEB-пакет на Ubuntu 24.04 / Debian с WebKitGTK 4.1. Установщик выдаёт только ядру `cap_net_admin,cap_net_raw,cap_net_bind_service`, чтобы TUN не требовал запуска WebView от root. Необходим доступный `/dev/net/tun`.

Автоматический системный прокси использует GNOME GSettings (GNOME-совместимые рабочие столы). Для KDE и других окружений используйте TUN либо настройте приложение на HTTP/SOCKS5 `127.0.0.1:17890`. Настройка GNOME не управляет KDE. AppImage запускается без установки; для TUN требуется извлечь AppImage и выдать capabilities бинарнику ядра или использовать DEB.

## Возможности

- Импорт VLESS (TLS/Reality, TCP/WS/gRPC/HTTP/HTTPUpgrade), VMess, Trojan, Shadowsocks SIP002/Base64, SOCKS5, HTTP(S).
- Сохранение UUID, пароля, SNI, Host, пути, serviceName, fingerprint, ALPN и параметров Reality.
- Импорт обычных и Base64-подписок; повторное обновление HTTPS-подписки заменяет её старые профили.
- Группы с failover: HTTP-проверка каждые 30 секунд, переключение после двух неудачных циклов, возврат на основной после успешной проверки. При ручном выборе сервер становится основным.
- Переключение сервера во время соединения через selector ядра после проверки нового сервера.
- Правила доменов: VPN / напрямую / блокировка. DNS over HTTPS, IPv6 в TUN, обход LAN, mux, sniffing, strict routing, блокировка QUIC.
- Реальная статистика и журнал ядра. Демонстрационные подключения, случайные скорости и синтетические соединения удалены.
- Снимок и восстановление системного прокси, контроль завершения ядра, защита от запуска двух экземпляров.

Shadowsocks-плагины, произвольные цепочки прокси и неподдерживаемые транспорты отвергаются с ошибкой. Пустых переключателей таких функций в интерфейсе нет. Автоматический перенос внутренней базы Qt-клиента не выполняется: экспортируйте его VPN-ссылки и импортируйте их в Oblique. Старый клиент и его настройки не изменяются. Данные web-прототипа `sg_*` читаются при первом сохранении в `oblique_*`; переход между разными идентификаторами установленного Tauri-приложения требует экспорта ссылок.

## Сборка

Нужны Node 22.13+, Rust stable не ниже 1.90, Go с закреплённым toolchain 1.25.7, зависимости Tauri для целевой ОС. Фиксация npm и Rust: `package-lock.json`, `src-tauri/Cargo.lock`. Фиксация движка: `core/SING_BOX_REVISION` и подмодуль `core/sing-box`.

```sh
git submodule update --init --recursive
npm ci
npm run build:core
npm run build
npm run tauri -- build --bundles deb,appimage  # Linux
# npm run tauri -- build --bundles nsis       # Windows
```

Для разработки `npm run dev`. Для просмотра только интерфейса `npm run dev:web`; VPN в браузере недоступен и не симулируется.

```sh
npm test
npm run lint
node --import tsx tests/core-integration.ts
npx playwright install chromium
npx playwright test
```

`tests/core-integration.ts` поднимает временные локальные VPN-серверы, проверяет TLS/TCP, WS и gRPC, реальные запросы, статистику, авторизацию API и отказ. Он не меняет системный прокси и маршруты. Для отдельной проверки личных профилей: `node --import tsx tests/check-live-profiles.ts /path/to/profiles.txt`; ключи не выводятся.

GitHub Actions собирает Windows и Linux и сохраняет установщики как artifacts, без автоматической публикации релиза.
